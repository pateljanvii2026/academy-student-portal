# 🎓 Academy Student Admission & Management Portal

A fully responsive and interactive web application for student registrations and directory management.

## 🚀 Live Demo
[Click here to view Live Site](https://pateljanvii2026.github.io/academy-student-portal/)

## ✨ Features
- 📝 Interactive Student Registration Form
- 📋 Real-time Data Entry into Enrolled Student Directory
- 🔍 Live Student Search Filter by Name
- 🖨️ Built-in Print/Export Feature for Directory
- 📱 Fully Mobile & Desktop Responsive Design

## 🛠️ Tech Stack Used
- HTML5
- CSS3 (Flexbox & Grid Layout)
- JavaScript (DOM Manipulation)
